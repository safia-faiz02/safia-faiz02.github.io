04 · Projects

Selected work

Featured

PaperPilot: Multi-Agent Literature Review Platform

A full-stack platform that searches arXiv, embeds papers locally, and writes citation-backed literature reviews. A self-correcting LangGraph pipeline (supervisor → synthesize → reflect) checks every generated citation against its source and retries when it finds a hallucinated one.

  • JWT auth with rotating refresh tokens and per-user data isolation
  • 26 automated tests plus GitHub Actions CI and a Docker build check
  • Prometheus metrics, LangSmith tracing, and Docker Compose setup

Urdu Image Captioning with Auditory Aid

Generates Urdu captions for images and speaks them aloud for visually impaired users. Transformer and encoder-decoder models (Xception, YOLOv8, LSTM/GRU) trained on MS COCO and Flickr30k translated to Urdu. The best model, a Transformer, reached a BLEU score of 0.538.
